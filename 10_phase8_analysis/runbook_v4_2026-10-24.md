# Execution order of the v4 pipeline (2026-10-24)

From the project root (`candida_multicompartment`). Prefix for all Python commands:
`conda run --no-capture-output -n ctrop_ma python -B` and for R: `conda run --no-capture-output -n ctrop_ma Rscript`.
No script overwrites anything: every output carries the date and time, and its log the MD5 of inputs and outputs. Rules: `10_phase8_analysis/analysis_rules_v4_2026-10-24.md`, `09_phase7_risk_of_bias/rob_rules_v3_2026-10-24.md`, `10_phase8_analysis/team_decisions_2026-10-24.md`.

**First time:** run the whole pipeline with `--provisional` (steps 1 to 6) to test it. The R scripts of this version have never been run: each one has `--check`, which validates inputs and formulas in seconds. Any error should be returned exactly as it appears.
