# Calibration of the screening manual (phase 2): sample and preparation

*Candida tropicalis* review. Written on 13 October 2026 at 16:35, Colombia time, before drawing the sample. Applies section 6 of the Methodological Approach v4.

## Sample

- Frame: the 22,403 works of the phase 1 screening corpus (03_phase1_deduplication/results/screening_corpus_phase1_n22403_2026-10-13.ris), sorted by their work identifier (O00001 to O22403).
- Size: 200 works, by simple random sampling without replacement.
- Seed: 13102026, with the Python 3 random generator (random.Random(13102026).sample).
- Script: 04_phase2_calibration/draw_calibration_sample.py. Outputs: calibration_sample_200_seed13102026.ris (verbatim RIS blocks of the representative records) and calibration_sample_200_seed13102026.csv (work, record, title, year).
- The model validation sample (phase 3) will be drawn later and will be disjoint from this one.

## Procedure (section 6)

- The two reviewers screen the 200 works independently and blind in Rayyan, with the registered criteria. Cohen's kappa is calculated.
- Discrepancies are discussed in order to write the application manual, not to change the criteria.
- If kappa falls below 0.60, a second round is run on 200 new works, with another seed declared before drawing.
- The manual is frozen, hashed and deposited before phase 3.

## Import into Rayyan

- Create a new review for the calibration only; do not use the historical review, which retains the state of the Rayyan deduplication.
- Activate blind mode before the reviewers enter.
- Rayyan will suggest possible duplicates on import: they are not resolved. Deduplication was closed in phase 1 and any merge in Rayyan would break the audit trail.
- Before importing the 200, import 3 or 4 test records and check whether Rayyan keeps the identifier (AN field). If it does not, decisions are matched using the sample's CSV file.
